AI 캐릭터 변환 설정

사진을 AI 이미지 서비스로 보내 싸이월드 미니미 스타일로 바꿔요. API 키는 이 기기 브라우저에만 저장돼요.

다른 폰·아이패드의 기본 카메라로 이 QR을 찍고 사파리에서 열면, 그 기기에 키가 저장돼요(두 앱 모두).
QR에 키가 들어 있으니 캡처하거나 단톡방에 올리지 마세요.

부스 운영 순서

  1. 등록 — 이름을 쓰고 [촬영] 또는 [사진 불러오기], 동의 체크 후 [대기 명단에 추가]. AI 변환이 바로 시작돼요(10~30초).
  2. 여러 명 동시 진행 — 변환을 기다리는 동안 다음 참여자를 계속 등록하면 돼요. 오른쪽 명단에서 상태를 확인하세요.
  3. 확인·조정 — 명단에서 이름을 누르면 카드가 보여요. 캐릭터를 드래그/크기 조절, 마음에 안 들면 [다시].
  4. 출력 — [포토카드 JPG 저장] → 샤오미 포토프린터 앱으로 인쇄 → 포토카드 케이스(키링)에 넣어 전달 → [출력 완료로 표시].
  5. 파일 전송 희망자 — [캐릭터만 PNG 저장]으로 캐릭터 이미지를 따로 저장해 보내 주세요.

폰·태블릿은 사파리(또는 크롬)에서 https 주소로 여세요. 카톡·파일 앱으로 html 파일을 열면 작동하지 않아요. API 키는 기기마다 한 번씩 넣어야 해요.

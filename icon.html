부스 운영 순서

  1. 사진 — [4컷 촬영]으로 포토존에서 바로 찍거나, 폰으로 찍은 사진을 [사진 불러오기]로 여러 장 넣어요. 사진을 누르면 선택된 칸(분홍 테두리)에 들어가요.
  2. 프레임 — 4가지 중 하나를 고르고, 그리드/스트립을 정해요. 칸을 드래그하면 사진 위치, 확대 막대로 크기를 맞출 수 있어요.
  3. AI 캐릭터형 — 동의 체크 후 [로블록스 캐릭터로 변환]. 4장 변환에 30초~1분 걸려요. 마음에 안 드는 칸은 [이 칸만 다시 변환].
  4. 저장 — [JPG 다운로드] → 샤오미 포토프린터 앱으로 인쇄.
  5. 다음 참여자 — 사진·변환 결과를 모두 지워요(원본 삭제 약속).

폰·태블릿은 사파리(또는 크롬)에서 https 주소로 여세요. 카톡·파일 앱으로 html 파일을 열면 작동하지 않아요. API 키는 기기마다 한 번씩 넣어야 해요.
